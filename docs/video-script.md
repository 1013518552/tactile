## 分镜

### 0:00–0:18 ｜ 钩子

**[画面]** 黑色背景，一行字慢慢打出来：

```
「我今天有点累」
```

**[口播]**

> 你跟 AI 说过这句话吗？
>
> 我每天都说。因为所有 AI 都靠一句话来认识你——**你自己描述自己。**
>
> 问题是，人不会准确描述自己。也不愿意每次都描述。

### 0:18–0:45 ｜ 问题

**[画面]** 屏幕录制：和一个 AI 的对话框，用户反复说「我没事」「还行」「有点累」，AI 只能回「那你休息一下」。

**[口播]**

> 你说「有点累」，它只能说「那你休息一下」。
>
> 它不知道你是**真的累**，还是**在敷衍它**；不知道你刚才已经连续敲了两小时键盘，还是刚睡醒。
>
> 因为**它看不见你的手**。

### 0:45–1:10 ｜ 它是什么

**[画面]** tactile 主窗口（`docs/images/main.png` 那一屏），鼠标依次划过：档位、间隔、已写 N 条。

**[口播]**

> 这个工具叫 **tactile**，中文我叫它**触觉软件**。
>
> 它只做一件事：**数你的手在动多少。**
>
> 敲了几个键、鼠标走了多少像素、停了多久、前台是哪个程序。
>
> 不认字、不看屏幕、不读窗口标题、不录音、不联网。

### 1:10–1:45 ｜ 演示（真实数据）

**[画面]** 打开面板 `127.0.0.1:18090`，绿条蓝条在动；然后打开 `data/2026-10-30.jsonl` 滚几行。

**[口播]**

> 这是它今天记的东西。
>
> 「这一分钟，敲了 214 个键，鼠标走了 1 万 8 千像素，最长停了 8 秒。」
>
> 就这些。**没有一句你打过的字。**
>
> 但 AI 拿到这一行，能判断的事比你想象的多：
>
> - 键多、鼠标少 → 在写东西
> - 键少、鼠标抖 → 在瞄、在找
> - 全静 → 走开了，或者卡住了

### 1:45–2:20 ｜ 隐私：三条 + 一道门

**[画面]** 设置窗口；然后点档位选 5 → 弹出倒计时门禁 → **录到手打「我明白」**。

**[口播]**

> 这东西最容易出事的地方，是隐私。所以我做了三条：
>
> **默认关。** 装完是档 0，什么都不采。
> **只在本机。** 数据是你硬盘上的一个文本文件。
> **能删。** 窗口里一键清空，可以选"彻底不留痕"。
>
> 还有一个档位我单独加了门——**档 5**，它会记录**你按了哪些键**。
>
> 想开它，得先看十秒说明，再**自己手打「我明白」三个字**，粘贴不算。

### 2:20–2:45 ｜ 限界（诚实那段）

**[画面]** 档位说明窗口（`docs/images/tiers.png`）。

**[口播]**

> 说清楚它做不到什么：
>
> **它不知道你在写代码还是在摸鱼**——档 3 只知道进程名。
> **它不是实时的**，默认一分钟聚合一次。
> **它只支持 Windows。**
>
> 而且我建议：**大多数人停在档 2 就够了。** 档 4、档 5 是给"我确实想知道"的人准备的。
>
> 工具不该因为能做，就默认做。

### 2:45–3:10 ｜ 为什么做

**[画面]** 回到黑底白字，缓慢打出：

```
「让我的动作和行为
  能触摸到你。」
```

**[口播]**

> 说实话，这个工具最早不是当产品做的。
>
> 是因为一句话——**「让我的动作和行为能触摸到你。」**
>
> 我想要的东西很简单：不用每次解释，它也知道我现在是什么样。

### 3:10–3:25 ｜ 收尾

**[画面]** 仓库页面 + 二维码（可选）。

**[口播]**

## 录制清单

| 要录的 | 怎么弄 |
| --- | --- |
| 主窗口 | 先采几分钟，让「已写 N 条」有数字 |
| 面板曲线 | 「打开面板」→ 一边动鼠标一边录，条子会跳 |
| 门禁 | 档位切 5 → 录全程（倒计时 + 手打「我明白」），**这一段的"慢"是卖点，别剪快** |
| 数据文件 | 用 VSCode/记事本打开 jsonl，滚两行即可 |
| 档位说明 | 点「各个档位的说明」 |

## BGM / 声音

- **BGM**：低频、无旋律优先（避免盖住口播）。音量 -24 LUFS 左右。
- **口播**：可以自己念；也可以让 TTS 念（这条线现在有我的声音）。
- **字幕**：全片加字幕，**关键数字加粗**（214 个键 / 1.8 万像素 / 0 上传）。
